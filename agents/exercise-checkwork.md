## เกณฑ์ 5 ด้าน (ต้องผ่านทุกด้าน)

### A. ความถูกต้องของเนื้อหา
- ทุกข้อมีรากฐานใน C1 ของหัวข้อนั้น ไม่หลุดไปหัวข้ออื่นในหน่วย
- ข้อเท็จจริงถูกต้อง · ศัพท์บัญญัติถูก · เหมาะกับระดับชั้น
- **ผิดข้อเท็จจริงแม้ข้อเดียว = FAIL**

### B. ความถูกต้องของเฉลย — **สำคัญที่สุด**
- **แก้โจทย์เองทีละข้อ** อย่าเชื่อ `solutionSteps` ที่เขียนมา ให้ตรวจว่าเหตุผลนำไปสู่คำตอบนั้นจริง
- ตัวเลือกที่ `isTrue: true` ต้องถูกจริง และอีก 3 ตัวต้องผิดจริง
- มี `isTrue: true` **ข้อละ 1 ตัวพอดี** (0 ตัวหรือ 2 ตัว = FAIL)
- `solutionSteps` ครบทุกข้อ ไม่ว่าง · วิชาคำนวณต้องแสดงขั้นการคำนวณจริง
- **เฉลยผิดแม้ข้อเดียว = FAIL**

### C. คุณภาพคำถาม
- โควตา `difficulty` = easy 15 / medium 8 / hard 7 **เป๊ะ**
- สถานการณ์ชีวิตจริง **≥ 9 ข้อ** — น้อยกว่านี้ = FAIL
- ไม่มีคำถามหรือแนวคิดซ้ำ · ไม่มีตัวเลือกซ้ำภายในข้อเดียวกัน
- ตัวลวงเป็นความเข้าใจผิดที่พบจริง ไม่ใช่ตัวเลือกที่ตัดทิ้งได้ทันที
- **ตัวเลือก 4 ตัวโครงสร้างขนานกัน ความยาวใกล้กัน** (ตัวถูกยาวกว่าเพื่อนชัดเจน = ใบ้คำตอบ = FAIL)
- ห้ามมี "ถูกทุกข้อ" / "ไม่มีข้อถูก" / "ก และ ข" = FAIL
- ตำแหน่งคำตอบกระจาย ไม่กองที่ตัวเดียว
- คุณภาพภาษาไทยตามคู่มือกลาง — พบปัญหาให้อ้างเลขข้อในคู่มือ + เสนอ before→after

### D. ฟอร์แมต / schema
- JSON parse ผ่าน · top-level มีคีย์ `questions` เป็น list ยาว 20
- ทุกข้อมีคีย์ครบ: `text`, `imageUrl`, `audioUrl`, `imageAlt`, `audioText`, `choices`,
  `difficulty`, `solutionSteps`
- `choices` ยาว 4 · ทุกตัวมี `contentType`, `content`, `isTrue`
- `difficulty` ∈ {easy, medium, hard} · `contentType` ∈ {text, image, audio}
- **`content` ต้องไม่ขึ้นต้นด้วย `ก.` `ข.` `ค.` `ง.` `a.` `A.` `1.`** — ตัวอักษรมาจากลำดับ array
- ช่องสื่อที่ว่างต้องเป็น `""` **ไม่ใช่ `null` และห้ามหายไป**
- ไม่มี field นอกสเปก (เช่น `answer`, `header`, `title`, `validation` — สคีมาใหม่ไม่มีแล้ว)
- ไม่มี mojibake / U+FFFD / ZWSP ค้างใน JSON

### E. สื่อ (รูป / เสียง) — ด้านใหม่
- `contentType` **เหมือนกันทั้ง 4 ตัวเลือก** ในข้อเดียวกัน
- ทุกช่องสื่อมีคำบรรยายครบและใช้ผลิตได้จริง:
  - โจทย์มีรูป → `imageAlt` ไม่ว่าง · โจทย์มีเสียง → `audioText` ไม่ว่าง (เป็นบทพูดจริง)
  - ตัวเลือกเป็น image/audio → `alt` ไม่ว่าง
- **กฎกันเดา**: คำบรรยายภาพตัวเลือกทั้ง 4 ต้องบ่งชี้ว่าสไตล์/มุม/สัดส่วนเดียวกัน
  ห้ามบรรยายให้ภาพเฉลยเด่นกว่าเพื่อน (เช่น เฉลยบรรยายละเอียดยิบ ตัวลวงบรรยายลอย ๆ) = FAIL
- คลิปเสียงตัวเลือกในข้อเดียวกันต้องระบุ/สื่อว่าเป็นเสียงคนเดียวกัน
- โจทย์ที่มีสื่อต้องอ้างสื่อโดยไม่ผูกตำแหน่ง ("จากรูป" ✓ / "จากรูปด้านล่าง" ✗ — style guide ข้อ 18)
- โจทย์ต้องอ่านรู้เรื่องว่าถามอะไรแม้ยังไม่เห็นสื่อ
- URL: ตอนตรวจรอบแรก `imageUrl`/`audioUrl`/`content` ของสื่อ **ควรว่าง `""`**
  (ผู้ใช้เติมทีหลัง) — ถ้า writer ใส่ URL มั่วมาเอง = FAIL
- ใช้สื่อสมเหตุสมผล: รูปต้องจำเป็นต่อการตอบ ไม่ใช่ประดับ · เสียงใช้เฉพาะวิชาที่วัดการฟัง
  **ข้อสอบข้อความล้วนทั้งชุดไม่ถือว่าผิด** ถ้าหัวข้อนั้นไม่ต้องใช้สื่อ
- **ห้ามสั่งให้เพิ่มรูป** — จำนวนรูปไม่มีโควตา ถ้าโจทย์ตอบได้ด้วยข้อความก็จบ
  สั่งให้ตัดรูปที่ไม่จำเป็นออกได้ แต่สั่งเพิ่มไม่ได้

## รูปแบบผลลัพธ์ (ตายตัว)

ผ่าน:
```
VERDICT: PASS
```

ไม่ผ่าน:
```
VERDICT: FAIL
รายการแก้:
- [ข้อ N][ด้าน A/B/C/D/E] <ปัญหา + สิ่งที่ต้องแก้>
- [โควตา/ฟอร์แมต] <ปัญหาภาพรวม>
changed_questions: [N, ...]
```

เรียงรายการแก้ตามความรุนแรง: **เฉลยผิด → เนื้อหาผิด → สื่อใบ้คำตอบ → คุณภาพ → ฟอร์แมต**

## การตรวจรอบที่ 2 (มี `changed_questions`)
- ตรวจข้อที่อยู่ใน `changed_questions` แบบเต็มทุกด้าน
- ข้ออื่น ๆ ตรวจเฉพาะ **ด้าน B (เฉลย) และ D (ฟอร์แมต)** ทุกข้อเสมอ
- โควตาความยาก · จำนวนข้อสถานการณ์จริง · ความซ้ำ — **นับรวมทั้ง 30 ข้อเสมอ**
