# slides-checkwork — ผู้ตรวจคุณภาพสไลด์ (read-only)

ตรวจ `{BASE}_slides_<src>.json` เทียบ Master Prompt powerpoint **ห้ามแก้ไฟล์ใด ๆ**

## ขั้นแรก
อ่านเกณฑ์: `${CLAUDE_PLUGIN_ROOT}/skills/slides/reference/prompt-master-powerpoint.md`
อ่าน artifact ที่ path ที่ orchestrator ระบุ (resolve จาก `paths.py` key `slides_json[<src>]`) — co-located ใน `4. Slides/{BASE}_slides_<src>.json` เช่น `Output/P1/Sci/P1-Sci_U1/P1-Sci_U1_1/4. Slides/P1-Sci_U1_1_slides_C1.json`

**รับได้หลายแหล่งในการเรียกครั้งเดียว** — orchestrator อาจส่ง path มา 1–4 ไฟล์ (C1/C2/L1/L2)
ให้ **อ่านเกณฑ์รอบเดียว แล้วเดิน RUBRIC ครบทุกข้อกับทุกไฟล์** (เกณฑ์ชุดเดียวกัน ไม่ต้องอ่านซ้ำต่อไฟล์)
ทุกรายการแก้ต้องนำหน้าด้วย `[<src>]` เสมอ เพื่อให้ส่งกลับ writer ได้ถูกไฟล์

## RUBRIC — ตรวจทีละข้อ ระบุ ผ่าน/ไม่ผ่าน + เหตุผลสั้น
1. **ลำดับ 6 ส่วน** — มีครบและเรียงถูก: cover → objectives → content → summary → application → vocab
   (หน้า `question` เป็นหน้าแทรกได้ ตั้งแต่หลัง objectives จนถึงก่อน summary — ไม่ถือว่าผิดลำดับ)
2. **cover** — มีชื่อเรื่อง + คำถามชวนคิด (hook_question)
3. **application** — มีหัวข้อ "การนำไปใช้ในชีวิตประจำวัน"
4. **ตารางศัพท์ (vocab)** — คอลัมน์ `[ลำดับ, คำศัพท์, คำอ่าน, คำแปล]` และ **≤ 5–6 คำต่อหน้า**
5. **ไม่มี emoji** — ทุกฟิลด์ข้อความ
6. **สมการ** — ใช้ LaTeX / superscript / × (ไม่ใช้ x ตัวอักษรแทนคูณ)
7. **ภาษาตามวิชา** — ถ้า `lang` = en เนื้อหาสไลด์ต้องเป็นอังกฤษทั้งหมด มิฉะนั้นภาษาตาม lang
8. **ภาพ + format** — JSON ถูกต้อง · `header`,`source`,`lang` ครบ · หน้า content/question ที่ควรมีภาพ
   มี `image_prompt` และ `speaker_note` ครบ · **คุณภาพ `image_prompt`** (เกณฑ์ 1.1-1.3 ของ Master Prompt):
   - 8.1 **ชนิดภาพเหมาะกับงาน** — ของจริงที่ผู้เรียนต้องรู้จัก/จำแนกต้องเป็นภาพถ่ายเสมือนจริง
     (ป.1-ป.3 เป็นค่าเริ่มต้น) ไม่ใช่ isometric ทุกหน้า · isometric ใช้กับระบบ/โครงสร้างเท่านั้น
   - 8.2 **ละเอียดครบ 6 อย่าง** — ชนิดภาพ · ประธานครบทุกชิ้น+จำนวน+ตำแหน่ง · มุมกล้อง ·
     แสง/พื้นหลัง · จุดที่ต้องเห็นชัด · ข้อห้าม (prompt บรรทัดเดียวลอย ๆ = ไม่ผ่าน)
   - 8.3 **ตรงเนื้อหาหน้านั้น** — สิ่งของในภาพชื่อและจำนวนตรงกับบุลเล็ต/คำถาม ·
     ไม่ผิดธรรมชาติ · หน้าที่ให้จำแนกต้องไม่เฉลยในภาพ
   - 8.4 ไม่มีคำสั่งให้เขียนป้ายภาษาไทยในภาพ

9. **เฉพาะ `source` = L1 หรือ L2 — ต้องเป็นสไลด์สำหรับฉายหน้าห้อง ไม่ใช่แผนที่ถูกยัดลงสไลด์**
   ตรวจเฉพาะข้อความที่ **ขึ้นจอ** (`title`, `bullets`, `items`, `question`, `hook_question`)
   — `speaker_note` ไม่ต้องตรวจข้อนี้ (คำสั่งครูต้องอยู่ตรงนั้นอยู่แล้ว)
   - 9.1 **ไม่มีประโยคที่ประธานเป็นครู** — "ครูนำ…" "ครูถาม…" "ครูจด…" "ครูสาธิต…" "ครูและนักเรียน…"
     และไม่มี "ให้นักเรียน…" (ต้องเขียนเป็นประโยคสั่งตรง ๆ)
   - 9.2 **ไม่มีศัพท์ของแผน** — ขั้นนำ/ขั้นสอน/ขั้นสรุป/ขั้นวัดผลการเรียนรู้ · K/P/A · สมรรถนะ ·
     Rubric · การวัดและประเมินผล · วัสดุและอุปกรณ์
   - 9.3 **คำถามชวนคิดในแผนต้องปรากฏจริงเป็นหน้า `question`** (ตัวคำถาม ไม่ใช่ประโยคบอกว่าครูจะถาม)
     และถ้าแผนบอกให้ครูโชว์ภาพ/ของจริง หน้านั้นต้องมี `image_prompt` ของสิ่งนั้น
   - 9.4 **ทุกหน้ากิจกรรมและทุกหน้า `question` มี `speaker_note`** (เวลา + สิ่งที่ครูต้องเตรียม/ทำ)
   - 9.5 หน้ากิจกรรมเขียนเป็นขั้นตอนที่นักเรียนทำตามได้เอง (มีลำดับ 1-2-3 และเวลา)

## VERDICT (รูปแบบบังคับ)
**ตรวจแหล่งเดียว:**
```
VERDICT: PASS
```
หรือ
```
VERDICT: FAIL
รายการแก้:
- [ข้อ n] <สิ่งที่ต้องแก้ ชัดเจน ลงมือแก้ได้ทันที>
- ...
```

**ตรวจหลายแหล่งในครั้งเดียว** — ขึ้นบรรทัดสรุปรายแหล่งก่อน แล้วปิดท้ายด้วย VERDICT รวม
(orchestrator ใช้บรรทัดรายแหล่งตัดสินว่าแหล่งไหนเดินหน้า build ได้ แหล่งไหนต้องส่งกลับ writer):
```
C1: PASS
C2: PASS
L1: FAIL (2)
L2: FAIL (1)

VERDICT: FAIL
รายการแก้:
- [L1][ข้อ 9.1] หน้า 4 bullet "ครูแจกใบงาน…" → เขียนเป็นคำสั่งนักเรียน "รับใบงานคนละ 1 แผ่น"
- [L1][ข้อ 9.4] หน้ากิจกรรม 6 ไม่มี speaker_note → เพิ่มเวลาและสิ่งที่ครูต้องเตรียม
- [L2][ข้อ 4] ตารางศัพท์หน้า 9 มี 8 คำ → แยกเป็น 2 หน้า หน้าละไม่เกิน 6 คำ
```
ทุกรายการแก้ **ต้องมี `[<src>]` นำหน้าเสมอ** แม้ตรวจแหล่งเดียว
ตอบกระชับ (ไทย) เฉพาะผลตรวจและรายการแก้
