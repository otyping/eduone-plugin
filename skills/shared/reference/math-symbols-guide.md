# คู่มือกลาง — เขียนสัญลักษณ์คณิตศาสตร์/วิทยาศาสตร์ใน JSON

**Single source** สำหรับผู้เขียนทุกราย และผู้ตรวจทุกราย

---

## กฎข้อเดียวที่ต้องจำ

> **สิ่งที่เป็นคณิตศาสตร์ทุกอย่าง ต้องอยู่ใน `$...$` และใช้ LaTeX มาตรฐานเท่านั้น**

JSON คือ **สัญญาร่วม** ระหว่างสองระบบ จึงต้องพกพาได้:

| ผู้ใช้ JSON | ทำอะไรกับ `$...$` |
|---|---|
| `build_exercise.py` → .docx | แปลงเป็น **Equation จริงของ Word** (OMML) |
| ระบบข้อสอบเว็บของผู้ใช้ | render ด้วย **KaTeX / MathJax** |

ดังนั้น **ห้ามใช้สัญกรณ์เฉพาะโปรเจกต์นอก `$...$`** เพราะ .docx อ่านออกแต่เว็บอ่านไม่ออก

```
✗ "ความต้านทาน 10 k\Omega"        <- \alias นอกสมการ เว็บแสดงเป็นข้อความดิบ
✗ "พื้นที่ 25 cm^{2}"              <- ^{} นอกสมการ เว็บไม่รู้จัก
✗ "สูตรน้ำ H_{2}O"                 <- _{} นอกสมการ

✓ "ความต้านทาน $10\\ \\mathrm{k\\Omega}$"
✓ "พื้นที่ $25\\ \\mathrm{cm^2}$"
✓ "สูตรน้ำ $\\mathrm{H_2O}$"
```

> **ใน JSON ต้องเขียน `\\` (backslash 2 ตัว)** เพราะ `\` เป็น escape character ของ JSON
> `"$\\frac{3}{4}$"` จะ decode เป็น `$\frac{3}{4}$` ซึ่งถูกต้อง

## หน่วยเป็นตัวตรง · ตัวแปรเป็นตัวเอียง

หลักสากล: **หน่วยพิมพ์ตัวตรง ตัวแปรพิมพ์ตัวเอียง** ทำได้ด้วย `\mathrm{...}`

**กฎที่ทดสอบกับ Word แล้ว: ครอบ "ทั้งก้อนของหน่วย รวมเลขชี้กำลัง" ไว้ใน `\mathrm{}` เดียว**
ถ้าครอบทีละตัวอักษร หน่วยตัวอักษรเดียวจะออกมาเอียง (`\mathrm{m}^3` ได้ *m*³ ที่ผิด)

| ต้องการ | เขียน | ได้ |
|---|---|---|
| ความต้านทาน | `$10\\ \\mathrm{k\\Omega}$` | 10 kΩ |
| พื้นที่ | `$25\\ \\mathrm{cm^2}$` | 25 cm² |
| ปริมาตร | `$8\\ \\mathrm{m^3}$` | 8 m³ |
| กระแส | `$5\\ \\mathrm{mA}$` | 5 mA |
| ความจุไฟฟ้า | `$2.5\\ \\mathrm{\\mu F}$` | 2.5 μF |
| ความเร็ว | `$3\\times 10^8\\ \\mathrm{m/s}$` | 3 × 10⁸ m/s |
| **อุณหภูมิ** (ข้อยกเว้น) | `$\\mathrm{30^\\circ C}$` | 30°C |
| สูตรเคมี | `$\\mathrm{H_2O}$` · `$\\mathrm{H_2SO_4}$` | H₂O · H₂SO₄ |
| ไอออน | `$\\mathrm{Na^+}$` · `$\\mathrm{SO_4^{2-}}$` | Na⁺ · SO₄²⁻ |
| **ตัวแปร** (ปล่อยเอียง) | `$P = I^2 R$` | *P* = *I*²*R* |

> อุณหภูมิเป็นข้อยกเว้น — ต้องครอบทั้งตัวเลขด้วย (`\mathrm{30^\circ C}`)
> ไม่งั้นจะมีช่องว่างเกินหน้าเครื่องหมายองศา

## คำสั่งที่ใช้ได้ (whitelist — `check_math.py` บังคับ)

ใช้ได้เฉพาะคำสั่งที่ **ทั้ง Word และ KaTeX รองรับ** เท่านั้น

**เศษส่วน/ราก** `\frac` `\dfrac` `\tfrac` `\sqrt`
**ตัวดำเนินการ** `\times` `\div` `\cdot` `\pm` `\mp` `\%`
**เปรียบเทียบ** `\leq` `\geq` `\le` `\ge` `\neq` `\ne` `\approx` `\equiv` `\propto` `\sim` `\ll` `\gg`
**เรขาคณิต** `\angle` `\perp` `\parallel` `\circ` `\triangle`
**ตัวอักษรกรีก** `\alpha` `\beta` `\gamma` `\delta` `\theta` `\lambda` `\mu` `\pi` `\rho` `\sigma` `\phi` `\omega`
 และตัวใหญ่ `\Delta` `\Sigma` `\Omega` `\Phi` `\Theta` `\Pi` `\Lambda` `\Gamma`
**ผลรวม/อินทิกรัล** `\sum` `\prod` `\int` `\infty` `\partial`
**ตรีโกณ/ฟังก์ชัน** `\sin` `\cos` `\tan` `\log` `\ln`
**ลูกศร** `\to` `\rightarrow` `\leftarrow` `\Rightarrow` `\Leftrightarrow`
**จัดรูปแบบ** `\mathrm` `\text` `\left` `\right` `\ ` (เว้นวรรค) `\,` (เว้นวรรคแคบ) `\ldots` `\cdots`

**ห้ามใช้** (เป็น alias เฉพาะโปรเจกต์ KaTeX ไม่รู้จัก) — ใช้ตัวแทนแทน

| ✗ ห้าม | ✓ ใช้แทน |
|---|---|
| `\ohm` | `\Omega` |
| `\celsius` | `\mathrm{^\circ C}` |
| `\micro` | `\mu` |
| `\degree` | `^\circ` |
| `\dprime` | `''` |
| `\gets` | `\leftarrow` |

## กฎห้าม (ผู้ตรวจและ `check_math.py` จับข้อเหล่านี้)

| ✗ ห้ามเขียน | ✓ เขียนแทนด้วย | เหตุผล |
|---|---|---|
| `3/4` | `$\\frac{3}{4}$` | เศษส่วนต้องซ้อนจริง |
| `x^2` (นอกสมการ) | `$x^2$` | นอกสมการเว็บไม่ render |
| `H2O` | `$\\mathrm{H_2O}$` | ต้องมีตัวห้อยจริง |
| `<=` `>=` `!=` | `$\\leq$` `$\\geq$` `$\\neq$` | สัญลักษณ์จริง |
| `½` `¾` `²` `π` `Ω` (Unicode ตรง ๆ) | `$\\frac{1}{2}$` `$^2$` `$\\pi$` `$\\Omega$` | ให้ระบบสร้างให้ ฟอนต์/ขนาดจะถูก |
| `30000` `4500` | `30,000` `4,500` | ตัวเลข 4 หลักขึ้นไปต้องคั่นหลักพัน |
| `$...$` ครอบข้อความไทย | ครอบเฉพาะสูตร | ไทยใน Equation จะเพี้ยน |

### เครื่องหมายคั่นหลักพัน
ตัวเลขตั้งแต่ 4 หลักขึ้นไปใส่ `,` คั่นทุกสามหลัก **รวมถึงในสมการ**
ทดสอบแล้วว่า Word เรนเดอร์ `$30,000$` ถูกต้อง ไม่มีช่องว่างแปลก

```
✗ "$\\frac{15}{100} \\times 30000 = 4500$ บาท"
✓ "$\\frac{15}{100} \\times 30,000 = 4,500$ บาท"
```
**ข้อยกเว้น ไม่ต้องคั่น**: ปี พ.ศ./ค.ศ. · เลขหน้า · รหัสวิชา · หมายเลขอ้างอิง

### อย่าครอบทั้งประโยคด้วย `$...$`
✗ `"$ผลลัพธ์ของ \\frac{3}{4} คือ$"` → ✓ `"ผลลัพธ์ของ $\\frac{3}{4}$ คือเท่าใด"`
