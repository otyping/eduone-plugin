# คู่มือกลาง — การใช้คำและภาษาไทยให้เป็นธรรมชาติ (EDU ONE / สพฐ.)

**Single source** สำหรับผู้เขียนทุกราย (`content-academic`, `content-narrative`, `exercise-writer`,
`lesson-plan-writer`, `song-writer`, `slides-writer`, `video-writer`, `game-writer`)
และผู้ตรวจทุกราย (`*-checkwork`). ใช้ **ทุกครั้ง** ที่เขียน/ตรวจข้อความภาษาไทยในโปรเจกต์นี้

เป้าหมาย: ทุกประโยค **อ่านครั้งเดียวเข้าใจ ไม่สะดุด ไม่กำกวม**

**ระดับภาษาปรับตามชั้น** (ข้อนี้สำคัญที่สุดของ EDU ONE — สพฐ. ครอบคลุม ป.1 ถึง ม.6):
- **ป.1–3** ประโยคสั้น คำพื้นฐาน 1 ประโยค 1 ใจความ เลี่ยงคำนามธรรม ใช้ของใกล้ตัว
- **ป.4–6** ประโยคยาวขึ้นได้ เริ่มใช้ศัพท์วิชาการพื้นฐานพร้อมอธิบายความหมาย
- **ม.1–3** ศัพท์เฉพาะทางได้ อธิบายครั้งแรกที่พบ ประโยคซับซ้อนขึ้นได้
- **ม.4–6** ศัพท์วิชาการเต็มรูป ใช้เหตุผลหลายขั้นได้

เขียนเสร็จให้ **อ่านในใจทุกประโยค** จับจุดที่ฟังแล้วแปลกแล้วแก้

> แต่ละข้อมีตัวอย่าง ✗ (เลี่ยง) → ✓ (ใช้)

## 1. เลี่ยงสำนวนแปลตรงจากอังกฤษ (translationese)
- ✗ "วิธีได้มาซึ่งความสามารถ" → ✓ "ที่มาของความสามารถ"
- ✗ "แทรกตัวอยู่รอบตัว" → ✓ "อยู่รอบตัว"

## 2. ความแม่นยำของคำ — เลือกคำให้ตรงความหมาย
คำที่ปกติสื่อ **ระยะทาง/กายภาพ** อย่านำมาใช้กับความ **คล้ายคลึง/นามธรรม** โดยตรง
- ✗ "ปรับให้**ใกล้**แบบนั้น" → ✓ "ปรับให้**ใกล้เคียงกับลักษณะ**นั้น"
- หลักคิด: ถ้าผู้อ่านต้องตีความเพิ่มว่าคำหมายถึงอะไร แปลว่าเลือกคำยังไม่ตรง

## 3. ระดับภาษาสม่ำเสมอ — โดยเฉพาะในรายการ/บริบทเดียวกัน
อย่าปนคำ **ลำลอง** กับคำ **กลาง** ในชุดเดียวกัน
- ✗ "(คน **หมา** ชายหาด อาหาร)" → ✓ "(คน **สุนัข** ชายหาด อาหาร)"
- สรรพนามเรียกผู้อ่าน/คำลงท้าย ใช้แนวเดียวกันทั้งไฟล์

## 4. เลี่ยงคำนามชนนามห้วน — ใส่คำเชื่อมความสัมพันธ์
- ✗ "สัญญาณง่วง" → ✓ "สัญญาณว่ากำลังง่วง" / "สัญญาณของความง่วง"

## 5. เลี่ยงความกำกวม — ระบุให้ชัดว่า "อะไร"
ประโยคต้องไม่ตีความได้หลายทาง และต้องไม่อ่านแวบแรกผิด
- ✗ "ถ่าย**หลายภาพซ้อน**" → ✓ "ถ่าย**ภาพหลายช็อตต่อเนื่องอย่างรวดเร็ว**"
- ✗ "สิ่งมีชีวิตไม่ใช่หุ่นยนต์มีความรู้สึก" → ✓ "สิ่งมีชีวิตไม่ใช่หุ่นยนต์ และมีความรู้สึก"

## 6. ไม่ใช้เครื่องหมาย "/" แทนคำเชื่อม
ระบุความสัมพันธ์ให้ชัดด้วยคำเต็ม "และ / หรือ / รวมถึง"
- ✗ "กฎ/ขั้นตอน" → ✓ "กฎและขั้นตอน"
- *ข้อยกเว้น:* "/" ที่มาจากชื่อหน่วย/หัวข้อในไฟล์หลักสูตร คงไว้ได้

## 7. คำเชื่อมเหตุ-ผลครบคู่
"ถ้า..." ต้องมี "...ก็จะ / ...แล้ว" รับ
- ✗ "ถ้าน้ำได้รับความร้อน น้ำกลายเป็นไอ" → ✓ "ถ้าน้ำได้รับความร้อน น้ำ**ก็จะ**กลายเป็นไอ"

## 8. หัวข้อ/หัวตารางเป็นวลีสมบูรณ์ · ไตเติลไม่ใส่หางลำลอง
- ✗ "เหมาะกับงานแบบ" → ✓ "เหมาะกับงานประเภทใด"
- ถ้าตั้งใจให้เป็นประโยค ต้องมีกริยา/คำลงท้ายครบ

## 9. คำขนานในรายการเดียวกันใช้รูปเดียวกัน  ← **สำคัญมากกับข้อสอบ**
- **ตัวเลือก 4 ตัวต้องโครงสร้างขนานกัน** (ขึ้นต้นแนวเดียวกัน รูปประโยคเดียวกัน ความยาวใกล้กัน)
- ถ้าตัวถูกยาวกว่าตัวลวงชัดเจน นักเรียนเดาได้โดยไม่ต้องคิด — ถือว่าข้อนั้นเสีย

## 10. เลี่ยงสรรพนามซ้ำ (โดยเฉพาะ "มัน")
- ✗ "**มัน**ไม่ได้โผล่มา... แต่**มัน**ทำงานเงียบ ๆ... จนคิดว่า**มัน**เป็นเรื่องธรรมดา"
- ✓ ปรับโครงสร้างประโยค / เรียกชื่อสิ่งนั้นตรง ๆ / ตัดทิ้งบางจุด

## 11. เลี่ยงอ้างอิงตำแหน่งบนสื่อ (medium-dependent reference)  ← **สำคัญมากกับเพลง/วิดีโอ/ข้อสอบเสียง**
อย่าอ้าง "ด้านล่าง / ข้างบน / ทางขวา" เพราะผูกกับเลย์เอาต์ ถ้าเปลี่ยนรูปแบบหรืออ่านเป็นเสียง ผู้รับสารจะงง
- ✗ "ลองดูตารางสรุป**ด้านล่าง**" → ✓ "ลองดูตารางสรุป**ต่อไปนี้**"

## 12. ไม่เอ่ยกลุ่มผู้เรียนซ้ำซาก
"นักเรียนชั้น ป.4" ทุกย่อหน้าทำให้จำเจ → สลับวิธีเรียก / ใช้สรรพนาม / ตัดในจุดที่ไม่จำเป็น

## 13. ตัวย่อ/ศัพท์อังกฤษ
เมื่อขยายความ **ครั้งแรก** ให้นำด้วย **คำเต็มอังกฤษก่อน แล้วตามด้วยคำแปลไทย** และ **อย่าใส่ตัวย่อซ้ำในวงเล็บ**
- ✓ "DNA ย่อมาจาก Deoxyribonucleic Acid หรือ กรดดีออกซีไรโบนิวคลีอิก"
- ✗ "กรดดีออกซีไรโบนิวคลีอิก (Deoxyribonucleic Acid, DNA)"
- ศัพท์อังกฤษทั่วไป คงรูป "ไทย (English)" ครั้งแรกครั้งเดียว เช่น "รูปแบบ (pattern)"

## 14. กระชับ — ตัด off-topic/เยิ่นเย้อ · เลี่ยงสำนวนลำลองเกิน
- ตัดประโยคที่ไม่ช่วยประเด็นหลักของย่อหน้า
- ✗ "โปรแกรมก็จะมึนทันที" → ✓ "โปรแกรมก็จะทำงานต่อไม่ได้ทันที"

## 15. เลี่ยงข้อความเชื่อมโยงโครงสร้างบทเรียน
ประโยคที่พูดถึง "หน่วยถัดไป/เรื่องหน้า" แทนการอธิบายเนื้อหาจริง → ตัดออก ให้เนื้อหา self-contained
- ✗ "...จึงสำคัญ **เพราะเราจะได้ใช้มันบ่อยมากในเรื่องต่อ ๆ ไป**" → ✓ ตัดส่วนหลังออก

## 16. เลี่ยงคำลดความหนักแน่น/คลุมเครือ (hedging)
- ✗ "ตัวอย่างที่**พอนึกออก**" → ✓ "ตัวอย่าง**ใกล้ตัว**"

## 17. ตัวย่อที่เคยขยายความแล้ว ไม่ขยายซ้ำข้ามเรื่องในหน่วยเดียวกัน (ต่อยอดข้อ 13)
ถ้าตัวย่อถูกขยายความเต็มไปแล้วในเรื่องก่อนหน้าของหน่วย เรื่องถัด ๆ ไปใช้ตัวย่อได้เลย

## 18. โจทย์ที่มีรูป/เสียง ต้องอ้างถึงสื่ออย่างถูกวิธี  ← **เฉพาะ EDU ONE (ข้อสอบมีสื่อ)**
- อ้างสื่อด้วยคำที่ไม่ผูกกับตำแหน่ง: ✓ "จากรูป" / "จากภาพที่กำหนดให้" / "ฟังคลิปเสียงแล้วตอบคำถาม"
  ✗ "จากรูปด้านล่าง" ✗ "ดูภาพทางขวา"
- โจทย์ต้อง **อ่านรู้เรื่องแม้ยังไม่เห็นสื่อ** ว่ากำลังถามอะไร (สื่อเป็นข้อมูลประกอบ ไม่ใช่ตัวคำถาม)
- ถ้าตัวเลือกเป็นรูป/เสียง ตัวโจทย์ต้องบอกชัดว่าให้เลือกจากอะไร
  ✓ "ภาพใดเป็นรูปสี่เหลี่ยมจัตุรัส" · ✓ "คลิปใดออกเสียงคำว่า cat ได้ถูกต้อง"
