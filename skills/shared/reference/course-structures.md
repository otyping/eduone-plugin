# แหล่งหลักสูตร — course-structure ที่มีอยู่ และวิธีเพิ่มใหม่

> ย้ายมาจาก `CLAUDE.md` — อ่านเมื่อ: จะเพิ่มวิชา/ระดับชั้นใหม่ · สงสัยว่า OBJ/COMP ของหน่วยเชื่อถือได้แค่ไหน
> (การ lookup ปกติใช้ `no_to_token.py` ซึ่งอ่านไฟล์เหล่านี้ให้เอง ไม่ต้องเปิดเอง)

ผู้ใช้จะวาง xlsx โครงสร้างหลักสูตร สพฐ. → ถอดเป็น `course-structure-<gradeSlug>-<subjectSlug>.md`
(รูปแบบดูที่ fixture `course-structure-p1-sci.md`): front matter
(GRADE/SUBJECT/SUBJECT_CODE/**PERIOD_MINUTES**/**LANG**) + ตาราง `| No. | หน่วย | เรื่อง |`
+ บล็อกระดับหน่วย OBJ/COMP + (option) บล็อก **PREREQ**

> ฟิลด์ **LANG** ขับ logic ภาษาของ song/slides/video; **PERIOD_MINUTES** ใช้ใน slides/lesson-plan

## `PREREQ|` — หัวข้อที่ต่อยอดจากหัวข้ออื่น

```
- PREREQ| 4 <- 2, 3        # No.4 ต้องรู้ No.2 และ No.3 มาก่อน
```
วางไว้ที่ไหนก็ได้ในไฟล์ (แนะนำเป็นบล็อกของตัวเองหลังตารางหัวข้อ) รับตัวคั่น `<-` `←` `:`

**ไม่ระบุ = ไม่มี prereq** — ค่าเริ่มต้นที่ปลอดภัย ระบุเฉพาะหัวข้อที่ต่อยอดกันจริง
และระบุเฉพาะ prereq **ทางตรง** (ไม่ไล่ย้อนทั้งสาย) เพื่อไม่ให้ writer อ่านเกินจำเป็น

`no_to_token.py` ตรวจให้ตอน parse — **ผิดข้อไหน exit ≠ 0 ทันที**:
No. ที่อ้างต้องมีอยู่จริง · ห้ามอ้างตัวเอง · ต้องอ้างหัวข้อที่มาก่อน (prereq < no) · ห้ามซ้ำ

**ใช้ทำอะไร**: `/content` ส่ง **path ของ `{BASE}_srcpack.md`** ของหัวข้อ prereq ให้
`content-academic` อ่านเอง (ไม่ส่งเนื้อหา — ตามกฎทองใน CLAUDE.md) เพื่อ
(ก) ไม่สอนซ้ำ (ข) ใช้ศัพท์/สัญกรณ์ชุดเดียวกัน (ค) เปิดหัวข้อด้วยการต่อยอดจากที่เรียนแล้ว
· `content-checkwork` ตรวจข้อ 8 (ความต่อเนื่อง) จากสิ่งเดียวกัน
· C1 เป็นประตูเดียว → ผลผลิตอีก 8 ชิ้นได้ความต่อเนื่องตามผ่าน srcpack อัตโนมัติ

**หัวข้อ prereq ยังไม่ได้ผลิต** (`ready: false`, `has_c1: false`) → ข้ามไป ไม่ใช่ error
แต่ orchestrator ต้องแจ้งในรายงานว่าเขียนโดยไม่มีฐานจากหัวข้อก่อนหน้า

> ความต่อเนื่องถูกเก็บเป็น **ไฟล์** ไม่ใช่ความจำใน context → `/clear` ระหว่างหัวข้อไม่ทำให้เสียอะไร
