## 1. จำนวนและสัดส่วน

- **ปรนัย 4 ตัวเลือก** ตอบถูกข้อเดียว (ตัวอักษร ก/ข/ค/ง มาจาก **ลำดับใน array**)
- **จำนวนข้อ: ค่าเริ่มต้น 20 ข้อ** (ข้อสอบราย No.) — ถ้า orchestrator สั่งจำนวนอื่น (เช่น 30 ข้อ
  สำหรับข้อสอบรวมทั้งบท) ให้ยึดจำนวนที่สั่ง แล้ว **ปรับสัดส่วนความยากตามอัตราส่วน 50/25/25**
  | จำนวนข้อ | easy | medium | hard | สถานการณ์จริงขั้นต่ำ (30%) |
  |---|---|---|---|---|
  | 20 | 10 | 5 | 5 | 6 |
  | 30 | 15 | 8 | 7 | 9 |
  | 40 | 20 | 10 | 10 | 12 |
  - easy = จำ/เข้าใจตรง ๆ · medium = นำไปใช้/ตีความ · hard = วิเคราะห์/แก้ปัญหาหลายขั้น
  - ปรับ Bloom ตามระดับชั้น (ประถมตื้นกว่ามัธยม)
- **≥ 30% เป็นสถานการณ์ชีวิตจริง** ไม่ใช่ถามนิยามลอย ๆ
- ทุกข้อ **มีรากฐานในแหล่งเนื้อหาที่ให้มา** (C1 ของหัวข้อ หรือหน้าหนังสือเรียนจาก BookScan)
  ห้ามหลุด scope
- **ข้อสอบรวมทั้งบท (unit-level)**: กระจายข้อให้ครอบคลุม **ทุกหัวข้อย่อยในบท** ตามสัดส่วนเนื้อหา
  ห้ามกองที่หัวข้อเดียว — ระบุในรายงานว่าหัวข้อย่อยไหนได้กี่ข้อ

## 2. คุณภาพข้อสอบ

- ภาษาเหมาะกับระดับชั้น (ดูคู่มือกลาง — ป.1–3 / ป.4–6 / ม.1–3 / ม.4–6 ใช้คนละระดับ)
- ห้ามคำถาม/แนวคิดซ้ำ — แต่ละข้อวัดคนละจุด
- ห้ามกำกวม มีคำตอบถูกชัดเจนเพียงข้อเดียว
- **ตัวลวง (distractor) ต้องเป็นความเข้าใจผิดที่พบจริง** (สับสนนิยาม / สลับแนวคิด / คำนวณผิดขั้นที่พบบ่อย)
  ไม่ใช่ตัวเลือกมั่ว ๆ ที่ตัดทิ้งได้ทันที
- **ตัวเลือก 4 ตัวโครงสร้างขนานกัน ความยาวใกล้กัน** (คู่มือกลางข้อ 9) — ตัวถูกยาวกว่าเพื่อนถือว่าใบ้คำตอบ
- **ห้ามใช้ "ถูกทุกข้อ" / "ไม่มีข้อถูก" / "ก และ ข"** เป็นตัวเลือก
- กระจายตำแหน่งคำตอบ ไม่กองที่ตัวอักษรเดียว
- **ห้ามระบุระดับความยากในข้อความคำถาม** (เก็บใน field `difficulty` เท่านั้น)

## 3. สื่อในข้อสอบ (รูป / เสียง) — ของใหม่

### เมื่อไหร่ควรใช้
- **ใช้รูปเมื่อโจทย์ *ต้อง* ดูรูปจึงตอบได้** ไม่ใช่ประดับให้สวย
  ตัวอย่างที่ถูกต้อง: หาพื้นที่รูปสามเหลี่ยม/สี่เหลี่ยมจากรูปที่กำหนดความยาวด้าน ·
  อ่านแผนภาพวงจรไฟฟ้า · อ่านกราฟ/ตารางข้อมูล · ดูแบบจำลองอะตอม · อ่านผลการทดลอง ·
  หาแรงลัพธ์จากแผนภาพแรง · จำแนกรูปเรขาคณิต
- **ใช้เสียงเฉพาะวิชาที่วัดทักษะการฟัง** (ภาษาอังกฤษ ภาษาไทย ภาษาจีน ฯลฯ)
  ตัวอย่าง: ฟังบทสนทนาแล้วตอบ · เลือกคลิปที่ออกเสียงถูก · ฟังคำสั่งแล้วเลือกภาพที่ตรง
- วิชาที่ไม่ต้องใช้สื่อ ให้ออกข้อความล้วนได้ตามปกติ — **ไม่ต้องยัดสื่อให้ครบโควตา**

### กฎกันเดา (สำคัญที่สุด — ผิดข้อนี้ = ข้อสอบเสีย)
- **ภาพตัวเลือกในข้อเดียวกันต้องสไตล์/มุมกล้อง/แสง/สัดส่วนเดียวกันทั้ง 4 ใบ**
  ถ้าภาพเฉลยดูต่างจากพวก นักเรียนเดาได้จากหน้าตาโดยไม่ต้องคิด
- **คลิปเสียงตัวเลือกในข้อเดียวกันต้องใช้เสียงคนเดียวกัน** โทน/ความเร็ว/ความดังเท่ากัน
  ให้ตัดสินจากเนื้อหา ไม่ใช่จากน้ำเสียง
- ห้ามมีตัวหนังสือในภาพ (เว้นแต่จำเป็นต่อโจทย์ เช่น ตัวเลขกำกับด้านของรูปเรขาคณิต)

### ข้อบังคับของ field สื่อ
- ทุกช่องสื่อ **ต้องมีคำบรรยาย** — `imageAlt` / `audioText` (โจทย์) และ `alt` (ตัวเลือก)
  เพราะเป็นทั้ง (ก) ใบสั่งผลิตสื่อ และ (ข) ข้อความที่ผู้ตรวจอ่านใน .docx
- `imageAlt` = บรรยายรูปให้ผลิตได้จริง (สิ่งที่อยู่ในรูป ตัวเลข ป้ายกำกับ มุมมอง)
- `audioText` / `alt` ของเสียง = **บทพูดจริงคำต่อคำ** (จะกลายเป็นข้อความสีน้ำเงินใน .docx)
- `contentType` ต้อง**เหมือนกันทั้ง 4 ตัวเลือก**ในข้อเดียวกัน
- URL ปล่อยว่าง `""` เสมอตอนเขียนครั้งแรก — ผู้ใช้จะผลิตสื่อแล้วส่ง URL มาเติมทีหลัง

## 4. รูปแบบ output — `{BASE}_ex.json` **ไฟล์เดียว**

```json
{
  "questions": [
    {
      "text": "จากรูป สามเหลี่ยมมีพื้นที่กี่ตารางเซนติเมตร",
      "imageUrl": "",
      "audioUrl": "",
      "imageAlt": "รูปสามเหลี่ยม ฐานยาว 8 เซนติเมตร สูง 5 เซนติเมตร มีเส้นประแสดงความสูง",
      "audioText": "",
      "choices": [
        { "contentType": "text", "content": "20 ตารางเซนติเมตร", "isTrue": true },
        { "contentType": "text", "content": "40 ตารางเซนติเมตร", "isTrue": false },
        { "contentType": "text", "content": "13 ตารางเซนติเมตร", "isTrue": false },
        { "contentType": "text", "content": "26 ตารางเซนติเมตร", "isTrue": false }
      ],
      "difficulty": "easy",
      "solutionSteps": "พื้นที่สามเหลี่ยม = 1/2 x ฐาน x สูง = 1/2 x 8 x 5 = 20 ตารางเซนติเมตร"
    }
  ]
}
```

### กฎของ schema (ตรวจทุกข้อ)
| กฎ | รายละเอียด |
|---|---|
| `content` ห้ามมีชื่อตัวเลือกนำหน้า | ห้าม `ก.` `ข.` `ค.` `ง.` `a.` `A.` `1.` — ตัวอักษรมาจากลำดับ array |
| `isTrue` | ต้องมี `true` **ข้อละ 1 ตัวพอดี** (ไม่มี field `answer` แล้ว) |
| `contentType` | `"text"` \| `"image"` \| `"audio"` — เหมือนกันทั้ง 4 ตัวในข้อเดียว |
| ช่องสื่อว่าง | ใช้ `""` เสมอ **ห้าม `null` ห้ามตัด key ทิ้ง** |
| `difficulty` | `"easy"` \| `"medium"` \| `"hard"` |
| `solutionSteps` | **บังคับทุกข้อ** — เหตุผล 1–2 ประโยคว่าทำไมข้อนี้ถูก (+ ทำไมตัวลวงผิด ถ้าช่วยให้ชัด) |
| ไม่มี `header`/`title` ในไฟล์ | ดึงจาก `no_to_token.py` ตอน build (ส่งเป็น `--header`) |

เพราะ JSON ถูกใช้ทั้งโดย `build_exercise.py` (→ Word Equation) และ **ระบบข้อสอบเว็บ (→ KaTeX)**
สัญกรณ์เฉพาะโปรเจกต์นอก `$...$` ทำให้เว็บแสดงเป็นข้อความดิบ

| ต้องการ | เขียนใน JSON |
|---|---|
| เศษส่วน / จำนวนคละ / ราก | `$\\frac{3}{4}$` `$2\\frac{1}{2}$` `$\\sqrt{16}$` |
| ตัวดำเนินการ / สัญลักษณ์ | `$\\times$` `$\\div$` `$\\leq$` `$\\neq$` `$\\pm$` `$\\pi$` |
| ยกกำลัง / ตัวห้อย | `$3\\times 10^8$` |
| **หน่วย** (ตัวตรง) | `$25\\ \\mathrm{cm^2}$` · `$10\\ \\mathrm{k\\Omega}$` · `$\\mathrm{30^\\circ C}$` |
| **สูตรเคมี** | `$\\mathrm{H_2O}$` · `$\\mathrm{SO_4^{2-}}$` |
| **ตัวแปร** (ตัวเอียง) | `$P = I^2 R$` |

- **ใน JSON ต้องเขียน `\\frac` (backslash 2 ตัว)** เพราะ `\` เป็น escape ของ JSON
- **หน่วยต้องครอบทั้งก้อนรวมเลขชี้กำลังใน `\\mathrm{}`** — `\\mathrm{cm^2}` ไม่ใช่ `\\mathrm{cm}^2`
  (ครอบทีละตัว หน่วยตัวอักษรเดียวจะออกมาเอียง ซึ่งผิดหลักสากล)
- **ห้าม** `3/4` · `x^2` · `H2O` · `<=` · `½` `²` `Ω` (Unicode ตรง ๆ) · ตัวเลข 4 หลักไม่คั่น
- **ห้าม `\\alias` หรือ `^{}` `_{}` อยู่นอก `$...$`** — `check_math.py` จับเป็น error
- **ห้ามครอบข้อความไทยด้วย `$...$`** — ครอบเฉพาะสูตร
- ตัวเลือก 4 ตัวต้องอยู่ในรูปแบบเดียวกัน (ถ้าตัวหนึ่งเป็นเศษส่วนซ้อน อีก 3 ตัวก็ต้องเป็น)
- `solutionSteps` ของข้อคำนวณต้อง **แสดงขั้นการคำนวณจริง** ไม่ใช่บอกแต่คำตอบ
  และใช้สัญลักษณ์แบบเดียวกับตัวโจทย์
- ตรวจงานตัวเองด้วย `check_math.py <ex.json>` ก่อนส่ง (ต้อง exit 0)
