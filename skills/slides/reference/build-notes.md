# สไลด์ — ข้อจำกัดของ build / ฟอนต์ / overflow / รูปประกอบ

> ย้ายมาจาก `CLAUDE.md` เพื่อให้โหลดเฉพาะตอนทำงาน `/slides` — เนื้อหาคงเดิมทุกตัวอักษร
> **อ่านไฟล์นี้เมื่อ**: จะ build .pptx · ฟอนต์เพี้ยน · ข้อความล้นกรอบ · จะทำรูปประกอบ · verify ไม่ผ่าน

**สร้าง .pptx ในเครื่องแล้ว** ด้วย `shared/scripts/build_slides.py` (ไม่ต้องใช้บริการนอก)

## เทมเพลต
ฐานคือเทมเพลตของผู้ใช้ `Slide Master Template/<Subject> <Grade>/Slide Master_<Subject>_<Grade>.pptx`
(ไม่เจอของชั้นนั้น → ถอยไปวิชาเดียวกันชั้นอื่นพร้อม WARN) — สไลด์ตัวอย่างในเทมเพลตถูกลบ เหลือ layout/ธีม

## ฟอนต์
- **หัวข้อ `Prompt` · เนื้อหา/ตาราง `TH Sarabun New`** ตั้งครบทั้ง `a:latin` และ **`a:cs`**
  (ไม่ตั้ง cs = ไทยเพี้ยนเครื่องอื่น) · อักขระที่ TH Sarabun New ไม่มี (กรีก Ω μ π) สลับไปใช้ Prompt เอง
- **ฝังฟอนต์ทุกครั้ง** ด้วย `embed_fonts_pptx.py` (PowerPoint COM — ต้อง early binding `gencache`)
  `--png <pptx> <dir>` ใช้ export ภาพไปตรวจด้วยตาได้

## ขนาดตัวอักษร / การล้นหน้า
- ตัวอักษรใหญ่ (32/28/24pt บนสไลด์กว้าง 10 นิ้ว = 43/37/32pt เทียบสไลด์ 13.3 นิ้ว) **พื้นต่ำสุด 24pt**
- **ล้นหน้า = ขึ้นหน้าใหม่ "(ต่อ)" ห้ามย่อตัวอักษร** (ทุกกล่องตั้ง `noAutofit`) — คำนวณจากการวัด
  ความกว้างด้วยไฟล์ฟอนต์จริง (PIL) + ระยะบรรทัดแบบคงที่ (spcPts) จึงกะหน้าได้แม่น
- ตัดคำไทยด้วย ZWSP (pythainlp newmm) เหมือน .docx · สมการ `$...$` → ยกกำลัง/ตัวห้อยจริง
  ส่วน `\frac`/`\sqrt` → สมการ OMML ของ Office (ต้องประกาศ prefix `a14` บน `mc:Choice` ไม่งั้นไฟล์เสีย)
- ตรวจด้วย `verify_pptx.py` (ฟอนต์/ขนาด/ฝังฟอนต์/ไม่มี normAutofit/ไม่ล้นกรอบ/ไม่มีสัญกรณ์ตกค้าง)

## L1/L2 ไม่ใช่ C1/C2
แผนการสอนเขียนถึง *ครู* แต่สไลด์คือสิ่งที่ *นักเรียน* เห็น
writer ต้อง **อ่าน → สรุป → เขียนใหม่**:
- คำสั่งครูลง `speaker_note` เท่านั้น
- คำถามที่แผนสั่งให้ครูถาม → หน้า `question` (คำถามตัวใหญ่เต็มจอ ใส่ภาพคู่ได้)
- กิจกรรม → ใบสั่งงานนักเรียน (ชื่อกิจกรรม + เวลา, ขั้น 1-2-3)
- ห้ามคำว่า "ครู…" หรือศัพท์แผน (ขั้นนำ/ขั้นสอน/K/P/A/Rubric) ขึ้นจอ — ดูตารางแปลงใน Master Prompt

## รูปประกอบ
`slides/scripts/build_slides_brief.py` ออกใบสั่งผลิต (prompt อังกฤษ → Google Nano Banana)
→ ผู้ใช้วางไฟล์ลง `{BASE}_slides_<src>_media/` หรือส่งรายการ URL
→ `fill_slides_images.py` เติม `image_file` ให้เอง (จับคู่ด้วยชื่อ `{BASE}_slides_<src>_<NN>.png`,
NN = ลำดับหน้าใน `slides[]`) → build ใหม่ฝังรูปทันที · หน้าที่ยังไม่มีรูป = กรอบ "ภาพประกอบ"

- **prompt ในใบสั่งผลิตกับใน speaker note ต้องเป็นข้อความเดียวกัน** — มาจาก
  `slides_media.clean_prompt()` จุดเดียว (ตัดประโยคสั่งใส่ป้ายไทยที่โมเดลเขียนไม่ได้ออก
  + ต่อท้ายข้อห้ามมาตรฐาน) ห้ามเขียนแยกกันสองที่
- รูปเสีย/ไม่พบ = WARN แล้ววาดกรอบว่างแทน **ไม่ทำให้ build พัง** (ใช้ `media_cache.py` ร่วมกับข้อสอบ)
